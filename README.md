# Wpipe Simple Workflow Example

This example demonstrates a basic workflow orchestration using Wpipe. It defines three Python functions as tasks and sets up dependencies between them, showcasing how Wpipe can manage sequential and parallel execution.

## Language

`python`

## How to Run

1. Install Wpipe: `pip install wpipe`
2. Save the code as `wpipe_example.py`
3. Run from your terminal: `python wpipe_example.py`
